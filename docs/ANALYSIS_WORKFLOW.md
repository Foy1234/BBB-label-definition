# Computational Analysis Workflow

## 1. Molecular identity and frozen data

BBBP and B3DB records are parsed with RDKit. The primary modeling identity branch applies the default `SaltRemover`, removes stereochemical annotations, and generates non-isomeric canonical SMILES and a full InChIKey independently from the same processed molecule. The first 14 InChIKey characters define the connectivity-level parent identity `parent_ik`. The frozen harmonized parent table is `data/frozen/consensus_dataset.csv`.

## 2. Stage I: hard-label construction audit

`code/stage1/` implements three prespecified construction factors:

- Identity: `parent_ik` / `canon_smiles`
- Repeated-record aggregation: first / majority
- Connectivity-level mixed-class handling: all / consistent

The eight nominal views collapse to three effective training states: First-all, Majority-all, and Consistent. XGBoost is evaluated on the fixed BBBP test set for overall discrimination, molecular scores, ranks, and seed variability. Fifteen mixed-class parents are compared with fifteen matched controls in the paired sensitivity analysis.

## 3. Stage II: evidence-retention training targets

`code/stage2/fit_corrected_targets.py` constructs the following targets on the common set of 1,157 training parents:

- Hard: representative binary class
- Vote: positive fraction across original repeated classification records
- Integrated: multichannel latent score combining B3DB classification, available training-side BBBP classification, and available continuous logBB measurements
- Smooth: class-conditional mean Integrated value assigned within each Hard class
- `I_lambda_0.01` and `I_lambda_1.0`: Integrated regularization-sensitivity targets

The same stage generates 99 conditional-permutation target arrays within strata defined by `(Hard, BBBP evidence availability, logBB evidence availability)`.

## 4. Stage III: model training

`code/stage3/stage3.py` trains XGBoost and GINE on the same training parents and target definitions.

- XGBoost: 20 random seeds
- GINE: 10 random seeds
- Conditional permutation: 3 paired seeds for XGBoost and 3 paired seeds for GINE

Evaluation sets are BBBP test, reference-out, and scaffold test.

## 5. Stage IV: molecule-level response and raw PAMPA evaluation

`code/stage4/finalize.py` uses seed-averaged predictions as the primary molecule-level analysis object and computes:

- AUROC and AUPRC
- paired-bootstrap target differences
- molecule-level prediction-score differences
- rank and rank-percentile differences
- Top-k candidate membership changes
- molecule-level summaries used for cross-encoder sensitivity analysis
- raw-score AUROC, AUPRC, Brier score, and ECE on NCATS PAMPA-BBB

PAMPA parents are connectivity-disjoint from the common supervised training set.

## 6. Stage V: chemical-space and structural associations

`code/stage5/chemspace.py` analyzes the 291 BBBP test parents using:

- Morgan-fingerprint PCA
- Moran's I in Morgan-similarity neighborhoods
- repeated Bemis-Murcko scaffolds
- 11 physicochemical descriptors
- frozen SMARTS structural rules

The analyses are applied to prediction-score sensitivity, rank-percentile sensitivity, and the maximum absolute deviation from Hard predictions.

## 7. Stage VI: cross-fitted PAMPA calibration

`code/stage6/pampa_calibration.py` reads the frozen Stage IV PAMPA predictions, averages the 20 XGBoost seeds at the parent level, and performs three 5-fold Platt cross-fitting repeats with split seeds 42, 43, and 44. Each calibrated value is generated by a calibrator fitted without that parent's label. Primary outputs are Brier score, 10-bin ECE, log loss, AUROC, and AUPRC.

## 8. Raw-evidence and structural-identity audits

`code/audits/evidence_reconstruction/` reconstructs Vote and logBB evidence directly from the original B3DB classification and regression tables and compares the reconstructed fields with frozen inputs.

`code/audits/structure_identity/full_inchikey_audit.py` retains source stereochemical annotations to generate full InChIKeys for the 15 connectivity-level mixed-class parent groups while reproducing `parent_ik` through the stereochemistry-removed branch. The audit covers 65 original classification records.
